# The corpus behind the published benchmark, as <filename> <url> [language].
#
# These documents are NOT redistributed in this repository: fetch.py downloads
# them from the publisher into data/raw/, where they become ordinary input like
# any file you would copy there yourself.
#
# The EU acts are fetched from Cellar (publications.europa.eu), the official
# machine-readable face of EUR-Lex. The eur-lex.europa.eu pages a human clicks
# now sit behind a JavaScript bot challenge and answer a script with an empty
# 202; Cellar is the documented way in and serves the same text. It negotiates
# format from the Accept header, which fetch.py derives from the extension
# below, and language from the third column (default "eng").
#
# Reuse terms of what is listed here:
#   EUR-Lex   Commission Decision 2011/833/EU — free reuse with acknowledgement
#   NIST      work of the U.S. government, public domain in the United States
#
# Deliberately excluded: ISO/IEC 42001 and other ISO standards are not freely
# redistributable and cannot be fetched by a public script.
#
# The filename becomes the document's id and the name shown under a citation,
# so it is chosen to read well there.

# ── The instrument the corpus is about ──────────────────────────────────────
# Regulation (EU) 2024/1689 — Artificial Intelligence Act. Full text: 113
# articles and 13 annexes, including the Annex III high-risk list. The PDF is
# the Official Journal layout, so citations resolve to a page and a bounding
# box; the Italian version exercises cross-language retrieval.
